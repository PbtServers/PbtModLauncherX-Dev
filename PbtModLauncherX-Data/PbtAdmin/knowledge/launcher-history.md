# Historia del launcher

Hecho documentado [official-launcher]: el repositorio público PbtServers/PbtModLauncherX-Dev es un fork de Voxelum/x-minecraft-launcher y presenta PbtModLauncherX como launcher adaptado de PbtServers con funcionamiento local/offline. Su README público identifica la versión 1.0.6. Fuente: https://github.com/PbtServers/PbtModLauncherX-Dev . Se conservan créditos y licencia MIT; independencia de servicios comerciales no significa borrar autoría.

Estado del desarrollo local [local-support]: la rama dev/upstream-v1.0.7 prepara mejoras de integración, branding, traducciones, loaders, shaders, versiones 26.x, iconos, primer inicio y servicios independientes. La versión oficial del código sigue siendo 1.0.6. Estos informes locales no prueban que se haya publicado una release 1.0.7 ni que todas las instalaciones reales se hayan validado.

Hecho documentado [official-profile]: el perfil público también enlaza PbtModLauncher-v2 como proyecto legacy archivado. No se infiere una cronología de migración ni fechas de fundación de estos enlaces.

Fuentes: official-launcher, official-profile y local-support en sources.json.
